# dotSharK 1.0.8

dotSharK 是一个轻量的 Windows yt-dlp 图形外壳，使用 **C#、WinForms 和 .NET Framework 4.8** 编写。程序使用暗色界面和绿色强调色，实际解析与下载由用户选择的 yt-dlp 完成。

## 运行

- 支持 Windows 10/11，需要 .NET Framework 4.8。
- 解压发布包后运行 `dotSharK.exe`，不需要安装 Visual Studio。
- 主界面、配置窗口和 EXE 都使用内嵌的小鲨鱼图标。

## 配置

在“配置…”中设置外部工具与 yt-dlp 选项：

- 可指定 `yt-dlp.exe`、`ffmpeg.exe`、`ffprobe.exe` 和 `deno.exe` 的路径。路径留空时，程序检查 EXE 同级目录和 `tools` 子目录。
- 外部工具页提供稳定版、Nightly/Canary 版本检查和更新。更新前会显示本地版本与远端版本，可选择更新、强制更新或取消。更新下载使用主代理；留空路径时写入 EXE 同级 `tools` 子目录。
- YT-DLP 页可设置 HTTP(S)/SOCKS 代理、地域验证代理、分片并发、同时下载数和 Cookie 来源；两个代理各有独立「启用」开关，关闭后保留地址，旧 INI 默认启用。
- 外部工具可指定 `aria2c.exe`；「高级下载」可填写按原网页 URL 域名匹配的 aria2c 站点（空格/换行分隔，例如 `youtube.com *.example.com`，普通域名默认包含所有子域名）。
- 「高级下载」可填 yt-dlp 原生命令行参数，支持带引号的参数值；同名参数会替换 dotSharK 自动参数，分析与下载均生效。
- 「高级下载 → 以下站点不使用代理」可按域名指定直连站点（例如 `bilibili.com`，自动覆盖所有子域名，按输入网页 URL 而非视频 CDN 匹配）。命中后跳过主代理、地域验证代理；如该站点也使用 aria2c，则显式覆盖 aria2c 的代理配置，保留其它 aria2c 设置。此规则优先于自定义 yt-dlp 的代理项。
- 中文输出改为原始字节解码：优先严格 UTF-8，若无效则尝试 GB18030，兼容 Windows 平台 yt-dlp/aria2c 的不同控制台编码，避免视频标题与日志出现 `����`。
- Cookie 可从浏览器配置或 Netscape 格式的 Cookie 文件读取。浏览器配置支持递归搜索；找到多个配置时优先选择 Cookie 数据库最新的一个。
- 代理配置以 URL 转义文本保存在 EXE 同级 `dotSharK.ini`，可跨用户和电脑携带；如代理含账号密码，请妥善保管此文件。旧 DPAPI 配置在原用户下仍可读取，下次保存转成便携格式。
- 下载目录可自定义；留空时保存到 EXE 同级的 `Downloads` 目录。

程序不读取 yt-dlp 外部配置文件，代理、并发、Cookie 与其他下载参数由 dotSharK 传给 yt-dlp。

## 视频与播放列表

- 视频格式列表显示分辨率、视频编码、HDR 类型、帧率、源容器与估算大小；同一分辨率的 AV1、VP9 等编码会分别列出。
- 视频质量限制默认展示最高的三个不同分辨率档；可在“配置 → YT-DLP”调整数量，填 `0` 显示全部分辨率档；同分辨率的不同编码与 HDR 选项仍分别保留。
- 检测到播放列表时，可选择下载单个视频或整个列表；列表项目可勾选，并统一设置质量、音轨、容器和字幕。
- 播放列表下载会自动建立同名子目录。
- 主界面显示下载队列、单项与队列实际进度；右键可独立「暂停此项」「继续/重试此项」，其余任务不中断；全队列停止、失败重试和清理功能保留。暂停通过终止当前 yt-dlp 进程实现，保留 .part 临时文件，下次调用 yt-dlp 依其 --continue 默认行为尝试续传（网站/协议可能不支持）。
- 主窗口位于前台时检测剪贴板中的完整 HTTP/HTTPS 链接，检测到后“分析链接”按钮绿色闪烁；点击按钮会自动填入并分析该链接。失去焦点时停止检测，不会自动开始下载。
- 浏览器右键发送链接直接加入**原有主界面队列**；来源列标记「浏览器」，同一队列里显示视频标题、进度、完成与失败状态。视频使用最高分辨率、最高帧率、同档优先 AV1 的自动策略，默认不下载整张播放列表。
- 浏览器任务仍使用「配置 → 静默下载」专用保存目录（默认 `Downloads\\Silent`）；手动任务继续使用原来的「保存到」。两类任务共用主队列的下载并发、日志、重试及停止功能。
- dotSharK 驻留系统托盘；浏览器右键发送时不会抢焦点，双击托盘即可打开原主界面；再启动 dotSharK.exe 会尝试恢复同一个窗口。扩展安装方法见 `BrowserExtension/README.md`。
- 主窗口与播放列表选择窗口会记忆大小、位置和最大化状态；播放列表选择窗口首次打开宽度为 1200px。显示器布局变化后会自动调整到可见区域。

## 从源码构建

源码位于 `src`。在安装了 .NET Framework 4.8 Developer Pack 的 Windows 环境中，使用 .NET SDK 构建：

```powershell
dotnet build src\dotSharK.csproj -c Release
```

构建输出位于 `src\bin\Release\dotSharK.exe`。项目不依赖 Visual Studio IDE。

## 便携运行

任务记录：`SilentQueue/Pending`、`SilentQueue/Active`，不使用已下载档案拦截重复下载；托盘日志：`Logs/tray-ui.log`。配置与已完成任务仍位于 EXE 同级。不同程序目录独立运行。旧 AppData 记录不自动迁移。

浏览器 Native Host 清单在 `BrowserExtension/NativeMessaging`；浏览器集成仍需注册，移动程序或换电脑需重跑安装脚本。自定义工具、Cookie、下载位置若配置为绝对路径，换盘或换电脑需调整；浏览器 Cookie 仍由浏览器自身管理。


## 单 EXE 运行

UI 程序集已嵌入 dotSharK.exe 并从内存加载，无需外置 DotSharK.UiFoundation.dll，也不会释放 UI DLL 到磁盘。覆盖 EXE 后可删除旧 UI DLL；浏览器插件和外部下载工具仍按原配置使用。
